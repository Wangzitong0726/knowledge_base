# AutoDL 操作清单

目标：**先把云端通路验通**（用 120 块的样例证明云端向量与本机一致），
等真语料切好再上传跑正式任务。

跑正式任务时只有**向量化**这一步上云。抓取、切块、BM25、问答页面全部留在本机。

---

## 第一步 · 租一台机器

进控制台 → **容器实例 → 租用新实例**。四处选择：

| 选项 | 选什么 | 理由 |
|---|---|---|
| **地区** | 随便，挑有 3090 现货的 | 与结果无关 |
| **GPU** | **RTX 3090**（¥1.32–1.68/时） | 我们模型只有 0.6B，8GB 显存都够。3090 是最省心的档；想再省可选 3080 / 2080Ti |
| **镜像** | **基础镜像 → PyTorch → 较新版本**（如 PyTorch 2.x + Python 3.10–3.12 + CUDA 12.x） | 自带 torch 和 CUDA，省一大截安装时间。**别选 TensorFlow/其它框架镜像** |
| **数据盘** | 默认 50GB 够 | 模型 1.2GB，语料几十 MB |

> ⚠️ **不要**选「无卡模式」去跑正式任务——没有 GPU 就退回本机 CPU 的速度了。
> 无卡模式（约 ¥0.1/时）只在**纯传文件**时用得上。

创建后**先别急着开机**，做第二步。

## 第二步 · 把 SSH 公钥填进去

在控制台找到 **SSH 公钥**设置（一般在个人设置 / 账号设置里），
新增一个公钥，把下面这一整行粘进去（**一字不改**）：

```
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIOQajxyUpKxhL0DcIZ3Y+tbBEWga7tzGglI/i7CnOIqm ai_homework3_autodl
```

> 这是我在这台电脑上生成的密钥对的**公钥**部分。公钥可以公开，
> 私钥留在本机、不外传。填完之后我就能直接连上去干活，你不用手工敲命令。
>
> 找不到这个设置项的话告诉我，我们改走密码方式。

## 第三步 · 开机，然后告诉我连接串

开机后进实例详情，找到 **SSH 登录指令**，形如：

```
ssh -p 12345 root@region-1.autodl.com
```

**把这一行原样发给我**（端口号和主机名），我就接下去接管：
装依赖 → 拉模型 → 上传样例 → 跑 → 核对与本机是否一致。

## 云端我会做什么（供你对照）

1. `pip install transformers`（torch 镜像里已有）
2. 从 ModelScope 拉 Qwen3-Embedding-0.6B 到 `/root/autodl-tmp`
3. 上传 `scripts/embed.py`、`scripts/build_vectors.py`、`data/chunks_demo.jsonl`
4. 跑 `--selftest` + 编码样例
5. **核对关键项**：云端向量的范数、以及四句测试句的相似度
   是否与本机修复后的真值一致（0.7862 / 0.3498 / 0.2121）
6. 若一致 → 通路验通，可以关机；等正式语料好了再开机跑十几分钟
