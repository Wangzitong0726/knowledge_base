### 模型作答（非原文，须逐条核 [n]）

```
**管制门槛（3A090.c 的物项范围）**

3A090.c 覆盖的是 HBM，门槛为 `memory bandwidth density` 大于 2 GB/s/mm²：

- 「High bandwidth memory (HBM) having a `memory bandwidth density' greater than 2 gigabytes per second per square millimeter.」[6][7][8]
- 另一种表述：「this IFR will control HBM having a `memory bandwidth density' greater than 2 GB per second per square millimeter (mm)」[1]

**门槛的技术定义（Technical Note 1 to 3A090.c）**

「`Memory bandwidth density' is the memory bandwidth measured in gigabytes per second divided by the area of the package or stack measured in square millimeters.」[6][7][8]；「In the case where a stack is contained in a package, use the memory bandwidth of the packaged device and the area of the package.」[6][7][8]

材料 1 的对应表述：「`memory bandwidth density' is the memory bandwidth of the package or stack measured in GB per second divided by the area of the package or stack measured in square mm」[1]。

**范围说明**

- 不要求符合 JEDEC HBM 标准：「High bandwidth memory (HBM) includes dynamic random access memory integrated circuits, regardless of whether they conform to the JEDEC standards for high bandwidth memory (HBM), provided they have a `memory bandwidth density' greater than 2 gigabytes per second per square millimeter.」[6][7][8]
- 材料 1 补充：现有量产的 HBM 堆栈全部超过该门槛：「All HBM stacks currently in production exceed this threshold.」[1]

**不要与另一个数字混淆**

`less than 3.3 GB/s/mm^2` 是 **License Exception HBM 下的授权条件**，不是 3A090.c 的管制门槛：「only authorized under this License Exception HBM if the 3A090.c item has a memory bandwidth density less than 3.3 GB/s/mm^2」[2][3]。

**许可要求（配套）**

对澳门或 Country Group D:5 目的地（含境内转移），ECCNs 3A090.c、3D001（for 3A090.c）、3E001（for 3A090.c）需许可证 [4][5]；该许可要求不适用于 deemed exports 或 deemed reexports [5]。此外，依 Sec. 734.9(h) 先进计算 FDP 规则，外国生产的 3A090.c 物项若符合该 FDP 规则范围亦受 EAR 管辖 [1]。

材料未覆盖：门槛数值的历史沿革、与其他 ECCN 门槛的比较、具体生效日期。
```

### 模型作答（非原文，须逐条核 [n]）

```
材料中能支撑的「影响面」主要有以下几项，但都停留在管制规则与公司定性表述层面，没有量化影响：

**1. 受控物项与目的地的许可要求**
- 对 specified in ECCNs `3A090.c`、`3D001 (for 3A090.c)`、`3E001 (for 3A090.c)` 的物项，在出口、再出口或境内转移至或发生在 Macau 或 Country Group D:5 目的地时须申请许可 [2][10]。
- 该许可要求不适用于 deemed exports 或 deemed reexports [10]。

**2. 许可例外 HBM 的可用范围与门槛**
- License Exception HBM 授权 `ECCN 3A090.c` 物项的出口、再出口、境内转移，但须满足全部条款条件 [1][4]。
- 主体资格受限：exporter、reexporter、transferor 须总部设在美国或 Country Group A:5 目的地，且无 ultimate parent 设在 Macau 或 Country Group D:5 目的地；「No other exporter, reexporter, or transferor may use License Exception HBM」[1][6]。
- 技术门槛：仅当 `3A090.c` 物项「memory bandwidth density less than 3.3 GB/s/mm[supcaret]2」时才可依该例外授权；「HBM at equal to or greater than this parameter … are not eligible for HBM」，理由是这类 HBM「of greater sensitivity」[6]。

**3. DRAM 定义与参数修订带来的受控面变化**
- 修订把 cell area 和 memory density 参数改为与 DRAM 行业 `18 nm half-pitch` 节点的生产标准一致，而非 IRDS 的理论定义 [3]。
- 该修订「imposes end use and U.S. persons controls at DRAM facilities not previously controlled by the definition of DRAM in the December 5, 2024 FDP IFR」[3]。
- 同时材料明确该次更新「does not restrict exports, reexports and transfers (in-country) of items covered by Sec. 744.23(a)(2) and the activities of U.S. persons Sec. 744.6 (c)(2)(i) to high bandwidth memory and other advanced DRAM applications」[3]。

**4. 企业层面的不确定性与需求端担忧（定性）**

```
## 结论：管制对象是 HBM，并非「整个 DRAM」

**管制条目：新增 ECCN 3A090.c**

- 这一轮 IFR 在 ECCN 3A090 下新增 items paragraph `.c`，对 certain HBM commodities 施加新的 CCL-based control [1]。
- 具体管的是 HBM stacks：「This IFR imposes these new controls on HBM stacks under ECCN 3A090.c」[2]。
- 管制理由：HBM 是制造 advanced computing ICs 的「production」过程中的重要组成部分，而在本 IFR 之前并未被 ECCN 3A090 覆盖 [2]；同时 PRC 的 indigenous advanced computing ICs 依赖 imported HBM，所以用 3A090.c 来 slow PRC attempts to indigenize advanced AI chip production [1]。

所以从材料看，落点在于带有特定技术属性的 HBM 这一类商品，而不是笼统的 DRAM。**材料未覆盖**普通通用 DRAM（如 DDR5、LPDDR5 等消费级/服务器内存）在这一轮中的管制状态，因此无法据材料断言「DRAM 整体不受管」或「DRAM 整体被管」。

## 技术线：用 bandwidth density，而非单纯 bandwidth

- BIS 明确选择用 **bandwidth density** 而不是 just the bandwidth，理由是要确保当 IC 使用「a larger quantity of smaller HBM chips at little additional cost」时管制仍然适用 [1]。也就是说，防止通过堆更多小颗粒来绕开按单颗带宽设的门槛。
- 材料中出现的唯一具体数值门槛是许可证例外（License Exception HBM）的适用条件：只有当 3A090.c item 的 memory bandwidth density **less than 3.3 GB/s/mm²** 时才可依该例外出口/再出口/境内转移 [5]；**equal to or greater than** 该参数的 HBM 属于 of greater sensitivity，不能适用该例外 [5]。
- 例外本身授权的是 ECCN 3A090.c 所列物项 [4]，且对 exporter / reexporter / transferor 的总部所在地有限制：须在美国或 Country Group A:5 目的地，且没有 ultimate parent 总部设在 Macau 或 Country Group D:5 目的地 [4]；其他主体不得使用该例外 [5]。

**需要注意区分**：3.3 GB/s/mm² 是「许可证例外能否用」的界线，不是 3A090.c 管制范围的完整定义。**材料未覆盖** 3A090.c 条目本身的完整技术参数（如带宽密度/容量的下限定义），只给了上述例外门槛。

## 管辖范围与一个边界情形

- 许可证要求：items specified in ECCNs 3A090.c、3D001 (for 3A090.c)、3E001 (for 3A090.c) 出口、再出口或境内转移至 or within Macau 或 Country Group D:5 目的地时须申请许可 [9]；该要求不适用于 deemed exports / deemed reexports [9]。
- 边界：**containing co-packaged logic and HBM 的 advanced computing ICs 不受 3A090.c 管**，但可能依其 TPP 和 performance density 落入 3A090.a 或 3A090.b [2]。即「HBM 颗粒/堆栈」与「已和逻辑共封装的成品芯片」走不同条目。

澜起科技同样在「(七) 宏观环境风险」下表述：「如果全球贸易摩擦进一步升级，有可能造成产业链上下游交易成本增加，下游需求受限，上游供给不畅」，「假如相关半导体出口管制政策进一步升级，不排除未来对公司业务及相关人员产生不利影响」[11]。请注意，这里提到的影响对象包括「相关人员」，这与东芯只讲供应链和成本不同[11]。

**2. 点名「实体清单」型：唯一在材料中直接写出机制的一家**

普冉股份写道：「随着美国商务部将多家中国企业和机构列入美国出口管制的『实体清单』，并且不断扩大『实体清单』名单，加强对『实体清单』的限制，加强对中国在先进制程领域发展的限制」[8]。它披露了两条具体传导路径：
